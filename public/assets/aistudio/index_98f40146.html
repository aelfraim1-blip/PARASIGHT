PARASIGHT

An AI-Based Microscopic Image Analysis System for Coproparasitological Parasite Detection

A research-based system concept designed to support the detection and classification of selected intestinal parasites in microscopic fecal images.

PARASIGHT is intended to support image analysis and present model outputs for human review. Its performance depends on the quality and representativeness of the dataset, verified annotations, and evaluation results. It should not be used as a standalone diagnostic tool.

Project workflow
Upload image → Quality check → Candidate-region screening → Human verification → Export report
